## Problem

A technical platform has to make sense to risk and compliance leaders, who are not engineers, in the first few seconds.

## Version 1: Webflow

1. **Problems before features.** Four risk cards came first, so the reader recognised their situation.
2. **A gated executive guide** as the main lead capture.
3. **Same design language as the consultancy site**, so the two brands supported each other.

## Version 2: code

The product pages now live inside aligne.ai, built in Astro from the same design system as the consultancy pages, and altrum.ai redirects there. A sub-navigation splits the product into Overview, Platform, Assessment agent, AI Gateway & MCP, Integrations, Use cases and Security, so each buyer can go straight to the part they care about.
