## Start from what the client will publish

List every page type the team will add after launch. Each one is a collection.

## Only the fields they'll fill in

If nobody will update a field, it doesn't belong in the CMS.

## Plan the references

Which collections link to each other? Blog to author, glossary term to post, service to case study.
