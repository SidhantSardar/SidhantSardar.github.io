## Things I already knew

- **Classes** in Webflow are CSS classes. Nothing new there.
- **CMS collections** are content collections in Astro, with a schema.
- **Components** with properties are Astro components with props.

## Things that were new

- Files and folders are the site map.
- Git keeps every version, so mistakes are cheap.
- The terminal stops being scary after day two.

## How I work with Claude Code

Describe the design like a handoff file. Ask for one change at a time. Read every diff.
